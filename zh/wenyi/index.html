我的 Mac 是哪种芯片？

点左上角苹果图标 → 关于本机。写着 芯片 Apple M1/M2/M3/M4 就选 M 芯片版；写着 处理器 Intel 就选 Intel 版。不确定就下通用版。

Mac 提示“无法打开”？

很多开源软件没有付费签名，第一次打开会被系统拦。确认是从上面按钮（作者官方发布）下载的，就打开 系统设置 → 隐私与安全性，往下拉点 仍要打开。完整安全清单。

能干嘛

Wenyi 是一款用于长篇作品翻译的桌面软件，特别适合小说和专著。它通过全书大纲、章节摘要和全局术语提取，确保整本书翻译时人名与术语一致。支持 EPUB、PDF、DOCX 等多种格式导入，还能导出双语排版。

适合谁

需要通读或翻译整本书籍、长篇论文的读者与译者。

不适合

平时只需随手查词、翻译单个网页或短句的人。

怎么开始

  1. 在 GitHub Releases 下载对应系统的桌面版安装包。
  2. 在设置中配置你的 AI 接口密钥（如 DeepSeek 等）。
  3. 导入书籍文件，即可开始翻译、校对和导出。

提醒

需要自备 AI 服务的 API Key（或配置本地 Ollama 模型）。

Wenyi 下载安全吗？

它是开源项目（GPL-3.0 授权），GitHub 2,919 星，最近更新 2026-11-13。只从本页的官方链接下载，安装前先扫一遍，具体做法见新手指南里的“下载安全”一节。

Wenyi 支持哪些文件格式？

Wenyi 支持 EPUB、PDF 和 DOCX 等常见书籍与长文档格式，并支持校对及导出双语排版对照。
