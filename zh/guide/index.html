第一次用开源软件？3 分钟看懂

开源软件就是把源代码公开、大多数免费的软件。它们通常放在一个叫 GitHub 的网站上。GitHub 本来是给程序员用的，所以页面看起来很复杂。其实普通人只需要找到"下载"那一步。

1. 先看本站给每个项目贴的标签

标签意思
下载即用像普通软件一样下载、双击安装就能用。
在线免费看教程或资料，点开网页就能读，不用安装。
需要简单设置装好后要填几项设置，比如选模型、填 AI 密钥。
需要命令行要在"终端"里输入命令，新手可以先跳过。
需自备 AI 密钥软件免费，但要接 OpenAI、Claude 等的 API 密钥（API Key），按用量付费给 AI 公司。
本地 AI 免费跑AI 在你自己电脑上运行，不花钱、不上传数据，但对电脑配置有要求（内存、显卡）。

2. 怎么下载

  1. 在本站打开一个软件，点蓝色的 Mac 下载按钮，它直接指向作者官方发布的 .dmg；没有 .dmg 时我们链接官网。
  2. 如果打开的是 GitHub 页面，找右侧的 Releases（发行版），点进去，在最新版本下面的 Assets 里挑适合你系统的文件。
  3. 不要点绿色的 Code 按钮下载源代码，那是给程序员的。
你的设备选这种文件
Windows.exe 或 .msi（文件名常带 windows、win、x64）
Mac.dmg（新款 Mac 选 arm64 或 apple silicon，老款 Intel 选 x64 或 intel，有 universal 就选它）
安卓手机.apk，或者直接去应用商店搜名字
iPhone一般去 App Store 搜名字

3. 打开时被系统拦住怎么办

很多开源软件没有花钱买苹果或微软的签名，第一次打开会弹出警告。先按第 4 步检查，确认是官方文件后，可以这样放行：

  • Windows：出现"Windows 已保护你的电脑"时，点"更多信息"，再点"仍要运行"。
  • Mac：提示"无法打开，因为无法验证开发者"时，打开系统设置 → 隐私与安全性，往下找到这个软件，点"仍要打开"。

只从官方链接下载。别人转发的安装包、网盘里的"破解版"不要装。

4. 下载安全：装之前先过这 8 关

开源不等于安全。代码公开，意味着有人可以检查，但不代表每个版本都有人检查过。本站只链接项目官方来源，但我们不审核代码。下面几步能挡住绝大多数风险：

  1. 认准官方来源。只从项目的官方 GitHub 仓库、官网或应用商店下载。看清仓库的作者名，小心名字很像的"山寨仓库"和搜索结果里的广告链接。
  2. 看它活不活跃。星多、最近还在更新、有很多人提问和回复，一般更可靠。刚建几天就星数暴涨、没人提问的项目，先观望。
  3. 文件类型要对得上。一个看视频的软件，却让你运行 .bat、.scr、.vbs 这类脚本，或者给你一个要输密码才能解压的压缩包，直接别装。
  4. 装前先扫毒。Windows 自带的 Defender 右键就能扫；拿不准的安装包，可以上传到 VirusTotal（virustotal.com）让几十个杀毒引擎一起查。
  5. 留意它要的权限。要管理员权限、"辅助功能"、录屏、读取全部文件的，想想它是不是真的需要。安卓装 APK 时临时打开"允许安装未知来源应用"，装完就关掉。
  6. 保护好你的 AI 密钥。只把 API 密钥填进你信任的软件；在 OpenAI、Anthropic 等后台设一个每月消费上限；给每个软件单独建一个密钥，不用了就删掉。
  7. 别乱复制命令。只运行项目官方 README 里写的安装命令。评论区、视频里、陌生人发来的命令，尤其是带 curl … | sh 或要你关杀毒软件的，一律不要执行。
  8. 拿不准就先隔离。可以先在一台旧电脑、或电脑上新建的一个普通用户账户里试用。用不上的软件及时卸载，常用的保持更新。

系统弹出的安全警告是在提醒你核对来源。按上面检查过、确认是官方文件，再按第 3 步放行。

5. 星数是什么

★ 是 GitHub 上的"收藏数"，类似点赞。星越多，用的人越多，一般也越靠谱，但不代表它适合你。先看"适合谁 / 可以跳过"。

6. 用不上了怎么删

和普通软件一样：Windows 在"设置 → 应用"里卸载；Mac 把它从"应用程序"文件夹拖到废纸篓。
