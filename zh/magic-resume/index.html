能干嘛

Magic Resume 是一个用来制作专业简历的在线工具。它提供左右分栏的实时预览、主题切换和自动排版为单页的功能。所有数据保存在浏览器本地，编辑完成后可以直接导出 PDF。

适合谁

正在找工作、希望快速排版出漂亮简历的人

不适合

已经有趁手的简历排版工具且不需要调整的人

怎么开始

  1. 用浏览器打开 magicv.art 官网
  2. 输入个人经历或导入已有内容
  3. 对照右侧实时预览调整并导出 PDF

提醒

若要使用内置的 AI 辅助撰写功能，需要自行配置模型服务商或 API Key。

是的，它完全免费，在浏览器中即可直接使用。如果使用其内置的 AI 辅助功能，需要自行配置 API Key。

Magic Resume 下载安全吗？

它是开源项目（NOASSERTION 授权），GitHub 11,415 星，最近更新 2026-11-02。只从本页的官方链接下载，安装前先扫一遍，具体做法见新手指南里的“下载安全”一节。
