QuickLook

按空格键快速预览文件内容

暂无 Mac 版。支持： Windows

去官网下载

GitHub 原址 · GPL-3.0

能干嘛

将苹果电脑上好评的“空格键预览”搬到了 Windows 系统。不需要双击并等待笨重的软件启动，只要选中文件按下空格键，就能秒开预览。支持图片、PDF、音视频、3D模型、代码和压缩包等上百种格式，还能通过插件继续扩展。

适合谁

经常需要查看文件内容、嫌每次开软件太慢的 Windows 用户。

不适合

Mac/Linux 用户，或习惯直接打开原软件的人。

怎么开始

  1. 从微软商店或 GitHub 安装 QuickLook。
  2. 在资源管理器中选中任意文件。
  3. 按下空格键立即预览或关闭。

提醒

微软商店版在部分软件的“打开/保存”弹窗中受限，需要该功能可选用独立安装包。
