能干嘛

uBlock Origin 是一款高效省资源的浏览器广告与内容拦截扩展。安装后无需繁琐设置，就能自动屏蔽广告、追踪器、弹窗和恶意网址。它不仅省内存，还能根据需要自定义过滤规则。

适合谁

想让网页变干净、远离弹窗骚扰的所有网民。

不适合

平时完全不用浏览器上网的人。

怎么开始

  1. 打开浏览器的插件扩展商店
  2. 搜索并安装 uBlock Origin
  3. 无需设置，直接打开网页即可生效

提醒

在 Firefox 上体验最佳；基于 Chromium 的浏览器正逐步限制旧版扩展技术。

是的，uBlock Origin 完全免费且开源，采用 GPL-3.0 许可证，无需购买或配置 API 密钥。

uBlock Origin 下载安全吗？

它是开源项目（GPL-3.0 授权），GitHub 69,306 星，最近更新 2026-11-13。只从本页的官方链接下载，安装前先扫一遍，具体做法见新手指南里的“下载安全”一节。
