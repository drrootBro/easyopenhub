完全离线运行的安卓实时双向语音翻译工具

暂无 Mac 版。支持： Android

去官网下载

能干嘛

这是一款在安卓手机本地离线运行的实时翻译应用。它内置语音识别与翻译 AI，无需连网即可将你说的话实时转译并播放给对方听。支持两人各戴蓝牙耳机互联对话，也支持单台手机像对讲机一样轮流讲话翻译。

适合谁

出国旅行或需要私密、离线双向语音对话的安卓用户

不适合

苹果手机用户，或运行内存不足 6GB 的旧手机用户

怎么开始

  1. 从 GitHub Releases 下载并安装 APK 安装包
  2. 首次打开应用，等待自动下载离线 AI 模型
  3. 选择对讲机或对话模式，直接开口交流

提醒

手机至少需要 6GB 运行内存，且初次启动需下载 1.2GB 模型文件。

常见问题

RTranslator 是免费的吗？

是的，RTranslator 完全免费且开源（采用 Apache-2.0 协议），无需购买订阅或配置 API 密钥。

RTranslator 下载安全吗？

它是开源项目（Apache-2.0 授权），GitHub 10,652 星，最近更新 2026-11-07。只从本页的官方链接下载，安装前先扫一遍，具体做法见新手指南里的“下载安全”一节。

RTranslator 可以完全离线使用吗？

可以。初次下载所需 AI 模型后，所有语音识别和翻译计算都在手机本地完成，无需连接互联网。
