为什么做 EasyOpenHub

很多好用的 Mac 软件是开源的：能干每月 10 美元订阅软件的活，装在自己电脑上，也没人能给你涨价。难的是找到它们。下载通常藏在 GitHub 上，那是给程序员用的网站，要翻过代码页、Releases，再从一堆叫 aarch64.dmg 的文件里挑对的那个。

我受够了一遍遍找文件，就把值得装的挑出来，每个都放上对的下载按钮。

下载是怎么来的（安全）

  • 直连作者。每个下载按钮都指向作者在自己 GitHub 官方发布或官网上放的文件。本站不托管、不转存、不修改、不捆绑。
  • 永远是最新正式版。脚本每天检查每个软件的最新官方发布，跳过测试版。按钮旁边写着版本号和日期。
  • 不接广告联盟，不套下载器。
  • 开源不等于审计过。我们只挑活跃、知名的项目，但不审代码。安装前请看安全清单。

怎么选软件

普通人不用命令行就能装、能在 Mac 上跑、尽量把数据留在自己电脑上、能替代大家真在付钱的软件。质量第一，不再维护的会被移除。

作者自研

标着「作者自研」的是本站作者自己做的软件，会明确标注，一次性买断，不搞订阅。

所有下载都直连原作者的官方发布，本站不托管、不修改、不捆绑，也不接广告联盟。
