我的 Mac 是哪种芯片？

点左上角苹果图标 → 关于本机。写着 芯片 Apple M1/M2/M3/M4 就选 M 芯片版；写着 处理器 Intel 就选 Intel 版。不确定就下通用版。

Mac 提示“无法打开”？

很多开源软件没有付费签名，第一次打开会被系统拦。确认是从上面按钮（作者官方发布）下载的，就打开 系统设置 → 隐私与安全性，往下拉点 仍要打开。完整安全清单。

能干嘛

OpenMotion 是一个开源的视频创作工作台，可作为 CapCut 或 Claude Motion 的替代方案。只要提供参考视频或链接，AI 智能体就能将其拆解为基于网页代码的镜头与时间轴，支持在可视化编辑器中修改节奏并导出 MP4。

适合谁

想按爆款视频风格快速替换自有品牌素材的创作者。

不适合

只想在手机上简单套滤镜剪辑的普通用户。

怎么开始

  1. 通过命令行拉取代码并使用 Node 启动
  2. 配置本地 AI 智能体或填入模型密钥
  3. 导入参考视频或模板并在编辑器中调整

提醒

需要熟悉命令行与 Node.js 环境，且生成素材需自备 AI API 密钥。

常见问题

OpenMotion 是免费的吗？

是的，它采用 Apache-2.0 开源协议供免费使用，但使用 AI 生成功能时需要提供自己的模型 API 密钥。

OpenMotion 下载安全吗？

它是开源项目（Apache-2.0 授权），GitHub 15,221 星，最近更新 2026-11-22。只从本页的官方链接下载，安装前先扫一遍，具体做法见新手指南里的“下载安全”一节。

OpenMotion 主要有什么用途？

它能通过 AI 分析参考视频并拆解为时间轴镜头，让你可以在可视化工作台中替换品牌素材并导出成品 MP4 视频。
