能干嘛

BentoPDF 是一个在浏览器里完全本地运行的 PDF 工具箱。它支持合并、拆分、修改文字、签名、格式转换及压缩等数十种功能。所有操作都在本地完成，文件绝不上传至任何服务器。

适合谁

经常需要处理 PDF 且非常在意隐私安全的人。

不适合

电脑里已经装好专业 PDF 软件的人。

怎么开始

  1. 用浏览器打开 bentopdf.com 网站。
  2. 选择你需要的功能（如合并、编辑或格式转换）。
  3. 拖入 PDF 文件处理并下载保存。

常见问题

BentoPDF 是免费的吗？

是的，BentoPDF 完全免费且开源（采用 AGPL-3.0 协议），无需付费订阅或购买 API 密钥。

BentoPDF 下载安全吗？

它是开源项目（AGPL-3.0 授权），GitHub 16,429 星，最近更新 2026-11-22。只从本页的官方链接下载，安装前先扫一遍，具体做法见新手指南里的“下载安全”一节。

BentoPDF 会把我的文件上传到服务器吗？

不会，所有的 PDF 处理和编辑都完全在你的浏览器本地进行，文件绝对不会上传到任何远程服务器。
