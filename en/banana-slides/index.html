Banana Slides creates presentation decks from simple prompts, documents, or outlines. It renders visually rich slides and allows you to modify specific sections using natural conversational commands. You can export results to editable PPTX, PDF, or video formats.

✓ Good for

Anyone needing quick, visual presentations without manual layout work.

✕ Skip it if

People who prefer designing slides manually in standard office software.

How to start

  1. Open the online demo or run the desktop app.
  2. Add your AI API key in the settings.
  3. Enter a topic prompt or outline to generate slides.

Requires your own AI model API key to generate slides.

Is Banana Slides free?

Yes, Banana Slides is open source under the AGPL-3.0 license, but generating slides requires your own AI model API key.

Is Banana Slides safe to download?
