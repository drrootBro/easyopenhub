Which Mac do I have?

Apple menu → About This Mac. If it says Chip: Apple M1, M2, M3 or M4, use Apple Silicon. If it says Processor: Intel, use Intel. Not sure? Universal works on both.

Mac says it can’t be opened?

Many open-source apps aren’t paid-signed by Apple, so the first launch shows a warning. If you downloaded it from the button above (the developer’s own release), open System Settings → Privacy & Security, scroll down and click Open Anyway. Full safety checklist.

What it does

ebook2audiobook transforms DRM-free ebooks and documents into audiobooks with preserved chapters. It supports over 50 text-to-speech engines, custom voice cloning, and thousands of languages. You can run it entirely on your own computer through a simple web interface.

Good for

People who want to listen to their own digital books.

Skip it if

Anyone looking for a one-click mobile app without setup.

How to start

  1. Clone the repository to your computer
  2. Run the launcher script for your operating system
  3. Open localhost:7860 in your browser to convert books

Heads-up

Modern voice engines are slow on CPU; a dedicated GPU is recommended.

Questions

Is ebook2audiobook free?

Yes, ebook2audiobook is completely free and open source under the Apache-2.0 license, running local text-to-speech models without paid API keys.

Is ebook2audiobook safe to download?

It is open source (Apache-2.0 license) with 20,550 GitHub stars, last updated 2026-11-12. Download only from the official link on this page, and scan the file before installing: see the safety checklist in our beginner guide.

Does ebook2audiobook work offline?

Yes, it runs entirely on your local computer through a web browser interface and converts your books without sending data to external servers.
