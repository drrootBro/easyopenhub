Which Mac do I have?

Apple menu → About This Mac. If it says Chip: Apple M1, M2, M3 or M4, use Apple Silicon. If it says Processor: Intel, use Intel. Not sure? Universal works on both.

Mac says it can’t be opened?

Many open-source apps aren’t paid-signed by Apple, so the first launch shows a warning. If you downloaded it from the button above (the developer’s own release), open System Settings → Privacy & Security, scroll down and click Open Anyway. Full safety checklist.

What it does

Meetily records meeting audio, transcribes it in real time, and writes AI summaries completely on your computer. Your audio and transcripts stay local without using cloud bots or uploading recordings. You can connect it to local models via Ollama or optional cloud AI providers for summaries.

Good for

People wanting private meeting transcriptions without leaking company discussions.

Skip it if

Anyone happy using cloud-based meeting recording bots.

How to start

  1. Download and install the desktop app.
  2. Select your microphone and system audio devices.
  3. Start meeting and generate real-time local notes.

Heads-up

Windows requires an AVX2 CPU; paid Pro plan needed for speaker identification and PDF/DOCX export.

Questions

Is Meetily free?

Meetily is freemium with core features under an MIT license, though advanced features like speaker identification and PDF/DOCX export require a paid Pro plan.

Is Meetily safe to download?

It is open source (MIT license) with 32,686 GitHub stars, last updated 2026-11-13. Download only from the official link on this page, and scan the file before installing: see the safety checklist in our beginner guide.

Does Meetily work offline?

Yes, Meetily records audio, transcribes, and generates summaries locally on your device using tools like Ollama without uploading your data to the cloud.
