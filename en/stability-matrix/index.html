Which Mac do I have?

Apple menu → About This Mac. If it says Chip: Apple M1, M2, M3 or M4, use Apple Silicon. If it says Processor: Intel, use Intel. Not sure? Universal works on both.

Mac says it can’t be opened?

Many open-source apps aren’t paid-signed by Apple, so the first launch shows a warning. If you downloaded it from the button above (the developer’s own release), open System Settings → Privacy & Security, scroll down and click Open Anyway. Full safety checklist.

What it does

It is an all-in-one desktop manager for AI image generation. It installs and updates apps like ComfyUI, Fooocus, or Automatic1111 with one click, without requiring manual Python setup. It also lets all installed apps share the same downloaded models to save disk space.

Good for

Anyone wanting local AI image generators without setup hassle.

Skip it if

People who prefer cloud image tools or manual command-line setups.

How to start

  1. Download and run the app for your computer.
  2. Pick an AI interface like Fooocus or ComfyUI to install.
  3. Browse models or launch the app to generate images.

Heads-up

Generating images locally still requires a computer with a capable GPU.
