New to open source? A 3-minute guide

Open-source software publishes its code, and most of it is free. It usually lives on a site called GitHub, which was built for programmers, so its pages look complicated. As a normal user you only need to find the download.

1. Read the labels on each project

LabelMeaning
Download & runDownload and install like any app.
Free to readA guide or course you read online. Nothing to install.
Some setupAfter installing you fill in a few settings, like choosing a model or adding an AI key.
Needs command lineYou type commands in a terminal. Beginners can skip these for now.
Needs your AI API keyThe app is free, but it connects to OpenAI, Claude and others with an API key, and you pay them by usage.
Free local AIThe AI runs on your own computer: no fees and nothing uploaded, but it needs enough memory or a decent graphics card.

2. How to download

  1. On this site, open an app and press the blue Download button for your Mac. It points straight at the developer’s official .dmg; when there isn’t one, we link the official website.
  2. If you land on GitHub, find Releases on the right, open the latest one, and pick the file for your system under Assets.
  3. Don’t use the green Code button. That downloads source code for programmers.
Your devicePick this file

Mac.dmg (newer Macs: arm64 / Apple silicon; older Intel Macs: x64 / intel; universal works on both)
Android.apk, or search the app store

3. If your computer blocks it

Many open-source apps aren’t paid-signed by Apple or Microsoft, so the first launch shows a warning. After the checks in step 4, if it’s the official file:

  • Windows: on "Windows protected your PC", click More info, then Run anyway.
  • Mac: if it "can’t be opened because the developer can’t be verified", open System Settings → Privacy & Security, scroll down and click Open Anyway.

Only download from official links. Never install "cracked" copies or files someone re-uploaded.

4. Download safety: 8 checks before you install

Open source is not the same as safe. Public code means people can review it, not that every release was reviewed. We only link official sources, but we do not audit code. These steps stop most problems:

  1. Use the official source. Download only from the project’s own GitHub repo, website or an app store. Check the owner name and watch for look-alike repos and ads in search results.
  2. Check that it’s alive. Many stars, recent updates and active questions and answers are good signs. A days-old repo with a sudden flood of stars and no discussion: wait.
  3. The file type should make sense. A video app that asks you to run a .bat, .scr or .vbs script, or a password-protected zip: don’t install it.
  4. Scan before installing. Right-click to scan with Windows Defender. For an installer you’re unsure about, upload it to VirusTotal (virustotal.com) to check it with dozens of antivirus engines.
  5. Watch the permissions. Admin rights, accessibility access, screen recording or full-disk access: ask whether the app really needs them. On Android, allow "install unknown apps" only while installing, then turn it off.
  6. Protect your AI keys. Paste an API key only into software you trust, set a monthly spending limit in your OpenAI or Anthropic dashboard, use a separate key per app, and delete keys you no longer use.
  7. Don’t paste random commands. Run only install commands from the project’s official README. Never run commands from comments, videos or strangers, especially ones with curl … | sh or that ask you to turn off antivirus.
  8. Unsure? Isolate it. Try it on an old computer or a separate standard user account first. Uninstall what you don’t use and keep the rest updated.

The system warning is a reminder to check where the file came from. Unblock it with step 3 only after these checks.

5. What the stars mean

★ is GitHub’s bookmark count, like a like. More stars usually means more users and a more reliable project, but not that it fits you. Check "Good for" and "Skip it if" first.

6. Removing an app

Same as any app: on Windows use Settings → Apps; on a Mac drag it from Applications to the Trash.
