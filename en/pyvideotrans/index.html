Which Mac do I have?

Apple menu → About This Mac. If it says Chip: Apple M1, M2, M3 or M4, use Apple Silicon. If it says Processor: Intel, use Intel. Not sure? Universal works on both.

Mac says it can’t be opened?

Many open-source apps aren’t paid-signed by Apple, so the first launch shows a warning. If you downloaded it from the button above (the developer’s own release), open System Settings → Privacy & Security, scroll down and click Open Anyway. Full safety checklist.

What it does

pyVideoTrans converts videos from one language to another automatically. It transcribes audio into subtitles, translates the text, generates spoken voiceovers, and combines everything back into a finished video. It works with both offline models and third-party online translation or speech services.

Good for

Video creators and educators translating content into multiple languages.

Skip it if

Anyone looking for a basic video editor without translation needs.

How to start

  1. Download the pre-packaged Windows version from Releases.
  2. Extract the archive to a clean folder path.
  3. Run sp.exe to open the desktop app.

Heads-up

macOS and Linux users must install dependencies like Python and FFmpeg manually.

Questions

Is pyVideoTrans free?

Yes, pyVideoTrans is completely free and open-source under the GPL-3.0 license, though using external third-party AI services may require your own API keys.

Is pyVideoTrans safe to download?

It is open source (GPL-3.0 license) with 19,753 GitHub stars, last updated 2026-11-15. Download only from the official link on this page, and scan the file before installing: see the safety checklist in our beginner guide.

Does pyVideoTrans work offline?

Yes, pyVideoTrans supports local offline models for transcription and voiceover, allowing you to process videos without sending data to external online services.
