Roubao (肉包)

An AI agent that operates apps directly on your phone

Not available for Mac. Platforms: iOS, Android

Get it from the official site

Source on GitHub · MIT

What it does

Roubao lets an AI look at your phone screen, tap, swipe, and type across apps to finish tasks. Once set up on iOS, it runs independently without keeping a computer connected. It supports custom vision AI models to compare products, make PDF summaries, and assist in apps.

Good for

Tinkerers wanting an automated AI agent on their smartphone

Skip it if

Anyone wanting a simple one-click install from the App Store

How to start

  1. Set up Xcode on a Mac to compile and sign iOS code
  2. Pair iPhone via USB and configure local device permissions
  3. Add your vision AI API key and start your first task

Heads-up

Requires compiling with Mac/Xcode and providing your own AI API key.

Questions

Is Roubao free?

Yes, Roubao is free and open-source under the MIT license, but you must supply your own vision AI API key to use it.

Is Roubao (肉包) safe to download?

It is open source (MIT license) with 2,420 GitHub stars, last updated 2026-11-09. Download only from the official link on this page, and scan the file before installing: see the safety checklist in our beginner guide.

Can I install Roubao directly from the App Store?

No, it is not available on the App Store and requires compiling with Xcode on a Mac to install on iOS.
