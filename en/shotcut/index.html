Which Mac do I have?

Apple menu → About This Mac. If it says Chip: Apple M1, M2, M3 or M4, use Apple Silicon. If it says Processor: Intel, use Intel. Not sure? Universal works on both.

Mac says it can’t be opened?

Many open-source apps aren’t paid-signed by Apple, so the first launch shows a warning. If you downloaded it from the button above (the developer’s own release), open System Settings → Privacy & Security, scroll down and click Open Anyway. Full safety checklist.

What it does

Shotcut is an open-source video editing application. It lets you import, trim, arrange, and edit your multimedia clips on a visual timeline. You can run it directly on your desktop across different operating systems.

Good for

Anyone looking for a free desktop video editor without paywalls.

Skip it if

People who only edit quick clips on mobile phones.

How to start

  1. Go to the official download page.
  2. Download the installer for your computer.
  3. Open the app and start editing videos.

Questions

Is Shotcut free?

Yes, Shotcut is completely free and open source under the GPL-3.0 license, requiring no subscriptions or API keys.

Is Shotcut safe to download?

It is open source (GPL-3.0 license) with 15,769 GitHub stars, last updated 2026-11-21. Download only from the official link on this page, and scan the file before installing: see the safety checklist in our beginner guide.

Does Shotcut work offline?

Yes, Shotcut is a standalone desktop application that runs entirely locally on your Windows, macOS, or Linux computer without needing an internet connection.
