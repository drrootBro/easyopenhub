Mika

An AI agent that operates Android apps for you

Not available for Mac. Platforms: Android

Get it from the official site

Source on GitHub · Apache-2.0

What it does

Mika is an Android assistant that controls apps and browses the web on a hidden background screen. You give it instructions in natural language, and it taps, types, and completes tasks without taking over your main screen. Your data stays on your phone, connecting directly to your chosen AI model provider.

Good for

Android users wanting an AI assistant to handle repetitive app tasks.

Skip it if

iPhone users or anyone looking for a zero-configuration plug-and-play app.

How to start

  1. Download and install the APK on Android 11+.
  2. Add an AI API key or log in.
  3. Pair wireless debugging to enable phone app control.

Heads-up

Controlling phone apps requires Android 12+ (Android 14+ recommended) and pairing wireless debugging.

Questions

Is Mika free?

Yes, Mika is free and open-source under the Apache-2.0 license, but you will need your own AI model API key or account to use it.

Is Mika safe to download?

It is open source (Apache-2.0 license) with 8,528 GitHub stars, last updated 2026-11-13. Download only from the official link on this page, and scan the file before installing: see the safety checklist in our beginner guide.

Does Mika disrupt how I use my phone?

No, Mika runs tasks and operates apps on a hidden background virtual screen, so you can continue using your phone normally.
