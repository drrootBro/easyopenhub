How to Live Better (Web Reader)

A searchable, offline-ready web guide for cost-effective living advice.

Not available for Mac. Platforms: Web

What it does

It turns the open-source book 'How to Live Better' into a single, clean webpage. It includes 528 practical life tips backed by scientific papers and sorted by cost-effectiveness. The page works offline, supports full-text search, and runs smoothly on phones.

Good for

Anyone looking for evidence-based life advice and practical habits.

Skip it if

People who already read the original Markdown files on GitHub.

How to start

  1. Open the website in any browser.
  2. Search keywords or filter by evidence grade.
  3. Read the advice cards and plain-language summaries.

Heads-up

The content is entirely in Simplified Chinese.
