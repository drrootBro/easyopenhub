Which Mac do I have?

Apple menu → About This Mac. If it says Chip: Apple M1, M2, M3 or M4, use Apple Silicon. If it says Processor: Intel, use Intel. Not sure? Universal works on both.

Mac says it can’t be opened?

Many open-source apps aren’t paid-signed by Apple, so the first launch shows a warning. If you downloaded it from the button above (the developer’s own release), open System Settings → Privacy & Security, scroll down and click Open Anyway. Full safety checklist.

What it does

LobsterAI is a desktop app that does real work on your computer. It can edit Office files, run local data analysis, browse the web, and generate presentations. You can also send commands to it from phone chat apps like WeChat, DingTalk, or Telegram.

Good for

Anyone needing an AI helper to complete desktop office tasks.

Skip it if

People who only want a simple web chatbot.

How to start

  1. Download and install the app for macOS or Windows.
  2. Sign in for built-in models or enter your key.
  3. Select a working folder and describe your task.

Heads-up

Computer control requires Windows x64 or macOS 13+.

Questions

Is LobsterAI free?

Yes, LobsterAI is free and open-source under the MIT license, allowing you to use built-in models or your own API keys.

Is LobsterAI safe to download?

It is open source (MIT license) with 6,186 GitHub stars, last updated 2026-11-13. Download only from the official link on this page, and scan the file before installing: see the safety checklist in our beginner guide.

Can I control LobsterAI from my phone?

Yes, you can remotely send commands and assign tasks to LobsterAI on your computer via mobile chat apps like WeChat, DingTalk, or Telegram.
