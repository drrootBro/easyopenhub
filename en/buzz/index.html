Which Mac do I have?

Apple menu → About This Mac. If it says Chip: Apple M1, M2, M3 or M4, use Apple Silicon. If it says Processor: Intel, use Intel. Not sure? Universal works on both.

Mac says it can’t be opened?

Many open-source apps aren’t paid-signed by Apple, so the first launch shows a warning. If you downloaded it from the button above (the developer’s own release), open System Settings → Privacy & Security, scroll down and click Open Anyway. Full safety checklist.

What it does

Buzz transcribes and translates audio on your own computer using OpenAI’s Whisper models. It handles files, YouTube links and live microphone input, can tell speakers apart, and exports TXT, SRT and VTT subtitles. A watch folder can transcribe new files automatically.

Good for

Journalists, students, podcasters and anyone transcribing interviews or meetings who doesn’t want to upload them.

Skip it if

You have an Intel Mac and want the newest version: Intel support stopped at 1.4.5.

How to start

  1. Use a download button above, or get the newest version from the official SourceForge page.
  2. Pick a Whisper model (smaller is faster).
  3. Drop in a file and export the transcript or subtitles.

Heads-up

The download buttons above are version 1.4.5 from GitHub, the last one that also runs on Intel Macs. Newer versions (Apple Silicon only) are on the official SourceForge page.
