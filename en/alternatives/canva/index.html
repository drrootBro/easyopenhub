OpenDesign

macOS, Windows, Linux, Web · ★ 107,531

Create prototypes, slides, images, and videos with AI agents. OpenDesign is a collaborative design workspace powered by AI. It connects to your existing coding agents or model API keys to turn written briefs into interactive web prototypes, presentation decks, graphics, and motion videos. Everything renders according to customizable design systems and templates.

Reactive Resume

Web, iOS, Android · ★ 45,989

Build, format, and track resumes with complete privacy. Reactive Resume is a free resume and cover letter builder. It lets you write with live PDF previews, choose from customizable templates, check ATS compatibility, and track job applications. Optional AI features can be enabled by connecting your own API key.

Magic Resume

Web · ★ 11,415

Modern online resume builder with real-time preview and export. Magic Resume is an online editor designed to build resumes easily. It features live visual preview, custom themes, and automatic one-page formatting. Content is stored locally in your browser and can be exported as a PDF.
