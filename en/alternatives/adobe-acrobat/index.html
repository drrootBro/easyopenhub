Stirling PDF

Web · ★ 96,524

Self-hosted all-in-one PDF editing tool platform. Stirling PDF is a private tool suite to edit, merge, split, sign, redact, and convert PDF files. It runs completely on your own machine or server without sending documents to third parties. You access all features through a simple web browser interface.

BentoPDF

Web · ★ 16,429

Process and edit PDF files entirely inside your browser. BentoPDF is an all-in-one PDF toolkit that runs completely on your device. It lets you merge, split, edit text, sign, convert, and compress documents. Because processing happens in your browser, your files are never uploaded to any remote server.
