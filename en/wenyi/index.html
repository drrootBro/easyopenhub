Which Mac do I have?

Apple menu → About This Mac. If it says Chip: Apple M1, M2, M3 or M4, use Apple Silicon. If it says Processor: Intel, use Intel. Not sure? Universal works on both.

Mac says it can’t be opened?

Many open-source apps aren’t paid-signed by Apple, so the first launch shows a warning. If you downloaded it from the button above (the developer’s own release), open System Settings → Privacy & Security, scroll down and click Open Anyway. Full safety checklist.

What it does

Wenyi is an open-source desktop app built for translating long-form works like novels, academic books, and essays. It analyzes chapter digests and term consistency across the entire book to prevent disjointed translations. It supports formats like EPUB, PDF, and DOCX, letting you edit paragraphs and export bilingual editions.

Good for

Readers and writers translating full books or lengthy manuscripts.

Skip it if

Anyone only needing quick single-sentence or casual web translations.

How to start

  1. Download the desktop app from GitHub Releases.
  2. Add your AI API key in Settings.
  3. Import a book file and click to translate.

Heads-up

Requires your own AI model API key (or local setup like Ollama).

Questions

Is Wenyi free?

Yes, Wenyi is free and open-source under the GPL-3.0 license, but you need to supply your own AI API key or connect a local model like Ollama.
